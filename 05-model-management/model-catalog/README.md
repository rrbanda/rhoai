# Model Catalog

## Status

**GA** (General Availability) — RHOAI 3.4

## Overview

The model catalog provides a curated set of validated third-party models for discovery, evaluation, and deployment. Users can browse available models directly from the RHOAI dashboard, deploy them to a serving runtime, or register them to the model registry for versioning and promotion. The catalog supports IBM Power (ppc64le) architectures.

## What's Covered

- Browsing and searching the curated model catalog from the RHOAI dashboard
- Evaluating model metadata, capabilities, and compatibility before deployment
- Deploying models directly from the catalog to a serving runtime
- Registering catalog models to the model registry
- IBM Power (ppc64le) platform support

Examples will cover browsing the catalog, deploying a model from the catalog to a single-model serving runtime, and registering a catalog model to the model registry for lifecycle management.
