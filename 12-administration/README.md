# Administration

**Status:** GA

Administering the Red Hat OpenShift AI platform. This section covers user management, hardware configuration, certificate management, and backup/restore procedures for operating RHOAI in production.

## What's Covered

- User access and RBAC configuration
- Hardware profiles for workload targeting
- TLS certificate and CA bundle management
- Platform data backup and restore

- [Provision Hardware Configurations and Resources](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/provision_hardware_configurations_and_resources_for_projects)
