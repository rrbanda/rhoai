# User Access and RBAC

**Status:** GA

User and group management, role-based access control (RBAC), identity provider integration, and OIDC authentication configuration for RHOAI 3.4. Control who can access platform resources and what actions they can perform.

## What's Covered

- Configuring identity providers (LDAP, OIDC, HTPasswd)
- Defining roles and role bindings
- Managing user and group permissions
- OIDC authentication setup
- Data Science Project access control

## Official Documentation

- [Configure User Access, Storage, and Telemetry in OpenShift AI](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/configure_user_access_storage_and_telemetry_in_openshift_ai)

## What's in examples/

Examples will include RBAC role definitions, identity provider configurations, group sync setups, and access policy templates for common organizational structures.
