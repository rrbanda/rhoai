# Certificates

**Status:** GA

Managing TLS certificates, custom CA bundles, and self-signed certificates for RHOAI 3.4 components. Ensure secure communication between platform services, model endpoints, and external integrations.

## What's Covered

- Configuring TLS certificates for RHOAI routes
- Adding custom CA bundles for internal PKI
- Managing self-signed certificates in development environments
- Certificate rotation and renewal procedures
- Troubleshooting certificate trust chain issues

## Official Documentation

- [Configure User Access, Storage, and Telemetry in OpenShift AI](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/configure_user_access_storage_and_telemetry_in_openshift_ai)

## What's in examples/

Examples will include certificate creation scripts, CA bundle ConfigMap templates, certificate rotation procedures, and troubleshooting guides for common TLS errors.
