# TrustyAI

**Status:** GA

TrustyAI provides model explainability and bias detection capabilities in RHOAI 3.4. Monitor model fairness across protected attributes, detect data drift over time, and configure metrics and thresholds to ensure responsible AI behavior in production.

## What's Covered

- Deploying and configuring TrustyAI
- Monitoring model fairness metrics (SPD, DIR)
- Detecting data drift with configurable thresholds
- Setting up alerts for metric violations
- Generating explainability reports (LIME, SHAP)

## Official Documentation

- [Monitoring Your AI Systems](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/monitoring_your_ai_systems)

Examples will include TrustyAI metric configurations, fairness monitoring dashboards, drift detection setups, and notebooks demonstrating model explainability techniques.
