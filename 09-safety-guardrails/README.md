# Safety and Guardrails

**Status:** GA

Ensuring AI safety with guardrails in Red Hat OpenShift AI 3.4. This section covers frameworks and tools for controlling LLM behavior, filtering harmful content, detecting sensitive data, and monitoring model fairness.

## What's Covered

- NeMo Guardrails for LLM conversation control
- TrustyAI for model explainability and bias detection
- Content filtering and sensitive data detection
- Topical guardrails and custom validation rules

Examples will include guardrail configurations for common safety policies, TrustyAI metric definitions, and end-to-end demonstrations of filtered inference pipelines.
