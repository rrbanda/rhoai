# Getting Started with Red Hat OpenShift AI 3.4

**Status:** GA

This section covers the foundational steps for getting up and running with Red Hat OpenShift AI (RHOAI) 3.4. From installing the operator and configuring your cluster to creating your first data science project and working through an end-to-end tutorial, these guides will help you go from zero to a working AI/ML environment on OpenShift.

## What's Covered

- **Platform Setup** -- Installing the RHOAI Operator, configuring the DataScienceCluster CR, and enabling components
- **First Project** -- Creating a data science project, launching a JupyterLab workbench, and running your first notebook
- **Fraud Detection Tutorial** -- An end-to-end walkthrough covering data exploration, model training, serving, and inference

## Official Documentation

- [Get Started with Projects, Workbenches, and Pipelines](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/get_started_with_projects_workbenches_and_pipelines_in_openshift_ai)

## What's in examples/

The `examples/` directory in each sub-folder contains sample manifests, scripts, and notebooks that complement the official documentation. Use them as starting points for your own projects.
