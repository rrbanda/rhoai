# Creating Your First Project

**Status:** GA

Walk through creating a data science project from the RHOAI dashboard, launching a JupyterLab workbench, and running your first notebook. This guide is intended for users who have completed platform setup and want to start working with notebooks and data.

## What's Covered

- Creating a new data science project from the RHOAI dashboard
- Launching a workbench with JupyterLab
- Selecting a notebook image (e.g., Standard Data Science, PyTorch, TensorFlow)
- Configuring compute resources (CPU, memory, GPU)
- Attaching persistent storage to your workbench
- Running and saving your first notebook

## Official Documentation

- [Get Started with Projects, Workbenches, and Pipelines](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/get_started_with_projects_workbenches_and_pipelines_in_openshift_ai)

## What's in examples/

Sample notebooks demonstrating basic data exploration and model training, along with workbench configuration snippets for common notebook image and resource combinations.
