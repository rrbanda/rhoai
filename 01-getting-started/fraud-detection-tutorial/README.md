# Fraud Detection Tutorial

**Status:** GA

A guided walkthrough of the official RHOAI fraud detection example. This tutorial takes you end-to-end: from exploring a sample dataset, through training a model, to deploying it for real-time inference. It is the recommended starting point for understanding the full AI/ML workflow on OpenShift AI.

## What's Covered

- Exploring and preparing the fraud detection dataset
- Training a classification model in a JupyterLab workbench
- Deploying the trained model using a model server (KServe / ModelMesh)
- Sending inference requests and interpreting predictions
- Cleaning up tutorial resources

## Official Documentation

- [OpenShift AI Tutorial -- Fraud Detection Example](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/openshift_ai_tutorial_-_fraud_detection_example)

## What's in examples/

Notebooks and scripts from the fraud detection tutorial, including the training notebook, sample inference payloads, and a cleanup script for removing deployed resources.
