# Feature Store

**Status:** TP (Technology Preview)

The Feature Store provides a centralized system for defining, storing, and serving reusable ML features to models. It ensures consistent feature engineering across both training and serving environments, reducing training-serving skew and enabling feature reuse across teams and projects.

## What's Covered

- Defining feature views and feature services
- Ingesting and materializing features from data sources
- Serving features online for real-time inference
- Retrieving historical features for model training
- Ensuring consistency between training and serving feature pipelines
