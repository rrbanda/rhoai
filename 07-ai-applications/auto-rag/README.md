# AutoRAG

**Status:** Developer Preview (DP)

AutoRAG automates the configuration and optimization of RAG pipelines. It evaluates and selects the best chunking strategies, embedding models, retrieval parameters, and reranking approaches for your data, removing the need for manual tuning of each pipeline stage.

## What's Covered

- Automated chunking strategy selection
- Embedding model evaluation and selection
- Retrieval parameter optimization
- Reranking approach configuration
- End-to-end pipeline assembly and evaluation
