# AI Applications

**Status:** Mixed (see individual components)

AI application development capabilities in Red Hat OpenShift AI 3.4. This section covers the tools and runtimes for building RAG pipelines, agentic workflows, and interactive model experimentation directly on the OpenShift AI platform.

## What's Covered

- **Llama Stack** (TP) -- Unified AI runtime for RAG and agent workflows, managed by the Llama Stack Operator
- **AutoRAG** (DP) -- Automated RAG pipeline configuration and optimization
- **Gen AI Playground** (TP) -- Interactive model experimentation and prompt testing from the RHOAI dashboard
- **MCP Servers** (TP) -- Model Context Protocol server discovery and integration for tool-calling agents
