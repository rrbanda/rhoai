# Llama Stack -- Agent Workflows

**Status:** Technology Preview (TP)

Agent-based AI workflows using Llama Stack. Build agentic applications that combine model inference, tool calling, and retrieval into autonomous multi-step workflows. Llama Stack exposes OpenAI-compatible agent APIs for defining and orchestrating agents.

## What's Covered

- Building agentic workflows with Llama Stack
- Combining inference, tool calling, and retrieval in agent pipelines
- OpenAI-compatible agent APIs
- Defining agent behaviors and tool integrations
- Multi-step reasoning and task execution
