# Llama Stack -- RAG Workflows

**Status:** Technology Preview (TP)

Retrieval-Augmented Generation (RAG) workflows using Llama Stack. Covers the full pipeline from document ingestion through context-grounded generation, including file management, chunking, embedding, vector storage, similarity search, and the Responses API for producing answers grounded in retrieved context.

## What's Covered

- File management and document ingestion
- Chunking strategies and embedding generation
- Vector store creation and configuration (milvus-lite, PostgreSQL with pgvector)
- Similarity search and retrieval
- Using the Responses API for context-grounded generation
- End-to-end RAG pipeline assembly
