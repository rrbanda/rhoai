# Gen AI Playground

**Status:** Technology Preview (TP)

Interactive model experimentation environment accessible from the RHOAI dashboard. Test prompts, compare models side-by-side, tune generation parameters, and apply safety guardrails -- all without writing code or deploying separate infrastructure.

## What's Covered

- Prompt testing and iteration
- Side-by-side model comparison
- Parameter tuning (temperature, top-p, max tokens)
- Applying and configuring safety guardrails
- Exporting prompts and configurations for downstream use
