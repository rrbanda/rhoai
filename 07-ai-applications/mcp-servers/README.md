# MCP Servers

**Status:** Technology Preview (TP)

Model Context Protocol (MCP) server discovery and integration in OpenShift AI. The AI Available Assets page provides a centralized view of deployed models and MCP servers, serving as an integration point for tool-calling agents and agent-to-agent communication.

## What's Covered

- AI Available Assets page for discovering deployed resources
- MCP server registration and discovery
- Integration with tool-calling workflows
- Agent-to-agent communication patterns
- Connecting MCP servers to Llama Stack and other runtimes

## Official Documentation

- [Working with Llama Stack](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/working_with_llama_stack)

Examples demonstrating MCP server registration, discovery via the AI Available Assets page, and integration with tool-calling agents and agentic workflows.
