# Pipelines and Distributed Processing

**Status:** GA

AI pipelines and distributed data processing in Red Hat OpenShift AI 3.4. This section covers Kubeflow Pipelines for ML workflow orchestration and Spark Operator for large-scale data processing.

## What's Covered

- Kubeflow Pipelines (KFP) for building and scheduling ML workflows
- SDG and training pipelines as reusable components
- Kubeflow Spark Operator for distributed data processing
- Artifact tracking and pipeline versioning

## Official Documentation

- [Creating Distributed Data Processing Applications](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/creating_distributed_data_processing_applications_with_the_kubeflow_spark_operator)

Examples will include pipeline definitions, component templates, Spark job configurations, and end-to-end pipeline orchestration patterns.
