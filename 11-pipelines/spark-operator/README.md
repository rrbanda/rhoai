# Kubeflow Spark Operator

**Status:** GA

The Kubeflow Spark Operator (KSO) enables distributed data processing applications on RHOAI 3.4. Run Apache Spark workloads natively on OpenShift for large-scale data preparation, feature engineering, and ETL tasks that feed into ML pipelines.

## What's Covered

- Deploying the Kubeflow Spark Operator
- Creating SparkApplication custom resources
- Configuring executor scaling and resource requests
- Running PySpark and Scala Spark jobs
- Integrating Spark outputs with ML pipelines

## Official Documentation

- [Creating Distributed Data Processing Applications with the Kubeflow Spark Operator](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/creating_distributed_data_processing_applications_with_the_kubeflow_spark_operator)

## What's in examples/

Examples will include SparkApplication manifests, PySpark data processing scripts, resource configuration templates, and patterns for connecting Spark jobs to KFP pipelines.
