# Kubeflow Pipelines (KFP)

**Status:** GA

Kubeflow Pipelines (KFP) in RHOAI 3.4 enables building, scheduling, and tracking ML pipelines as reproducible workflows. Version pipeline definitions, schedule recurring runs, and track artifacts in S3-compatible storage for full experiment lineage.

## What's Covered

- Building pipelines with the KFP SDK
- Scheduling and triggering pipeline runs
- Versioning pipeline definitions
- Tracking artifacts and metrics in S3-compatible storage
- Monitoring pipeline execution and debugging failures

## Official Documentation

- [Build, Schedule, and Track Machine Learning Pipelines](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/build_schedule_and_track_machine_learning_pipelines)

## What's in examples/

Examples will include pipeline definitions using the KFP SDK, custom component templates, pipeline scheduling configurations, and artifact storage setup guides.
