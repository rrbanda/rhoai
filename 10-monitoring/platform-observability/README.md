# Platform Observability

**Status:** Technology Preview (TP)

Centralized platform observability for RHOAI 3.4 providing zero-config GPU monitoring, native vLLM inference metrics, and OpenTelemetry-compatible tracing. Gain unified visibility into platform health, resource utilization, and inference performance without manual instrumentation.

## What's Covered

- Zero-config GPU utilization monitoring
- Native vLLM serving metrics (latency, throughput, queue depth)
- OpenTelemetry-compatible distributed tracing
- Centralized observability dashboards
- Correlating infrastructure metrics with inference performance
