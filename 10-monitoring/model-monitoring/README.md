# Model Monitoring

**Status:** GA

Monitor model bias and data drift in production by configuring metrics, thresholds, and visualizations. Detect when model behavior degrades or shifts from expected baselines, and trigger alerts to maintain model quality over time.

## What's Covered

- Configuring fairness and drift metrics
- Setting thresholds and alerting rules
- Visualizing model behavior with dashboards
- Scheduling periodic metric evaluations
- Integrating with Prometheus and Grafana
