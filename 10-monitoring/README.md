# Monitoring

**Status:** GA

Monitoring AI systems in Red Hat OpenShift AI 3.4. This section covers tools and configurations for observing model behavior in production, tracking platform health, and managing usage telemetry.

## What's Covered

- Model monitoring for bias and data drift
- Platform observability with GPU and inference metrics
- Usage telemetry configuration and auditing
- OpenTelemetry-compatible tracing
