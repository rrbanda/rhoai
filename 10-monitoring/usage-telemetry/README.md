# Usage Telemetry

**Status:** GA

Understanding, controlling, and auditing usage telemetry in RHOAI 3.4. Configure opt-in/opt-out settings, understand what data is collected, and audit telemetry transmission for compliance and governance requirements.

## What's Covered

- Understanding what telemetry data is collected
- Configuring opt-in and opt-out settings
- Auditing telemetry transmissions
- Compliance considerations for air-gapped environments
- Telemetry data retention policies

## Official Documentation

- [Understand, Control, and Audit Usage Telemetry in OpenShift AI](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_self-managed/3.4/html/understand_control_and_audit_usage_telemetry_in_openshift_ai)

## What's in examples/

Examples will include telemetry configuration snippets, audit log inspection scripts, and opt-out configuration for disconnected environments.
