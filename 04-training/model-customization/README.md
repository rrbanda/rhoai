# Model Customization (Training Hub)

**Status:** GA

Training Hub provides a unified Python API for LLM post-training. It supports multiple customization algorithms -- SFT, OSFT, LoRA, and GRPO -- and consumes JSONL data generated by SDG Hub. Training Hub handles the full lifecycle from data ingestion through checkpoint management.

## What's Covered

- **SFT** -- Full-parameter supervised fine-tuning
- **OSFT** -- Orthogonal subspace fine-tuning to prevent catastrophic forgetting
- **LoRA** -- Parameter-efficient fine-tuning with reduced VRAM requirements
- **GRPO** -- Reinforcement learning from verifiable rewards for tool-calling agents

## What's in examples/

Examples demonstrate each algorithm end-to-end: preparing JSONL datasets from SDG Hub output, configuring training parameters, launching jobs, and loading the resulting model for inference.
