# RAG Application End-to-End

**Status:** GA

Build and deploy a retrieval-augmented generation (RAG) application using Llama Stack and vLLM on RHOAI 3.4. Covers the full stack from model deployment through document ingestion to exposing RAG endpoints via the Llama Stack Responses API.

## What's Covered

- Deploying a model with KServe/llm-d for inference
- Setting up vector storage for document embeddings
- Ingesting and chunking documents for retrieval
- Configuring Llama Stack for RAG orchestration
- Exposing RAG endpoints via Llama Stack Responses API

## Official Documentation

Examples will include model serving manifests, vector database deployment configs, document ingestion scripts, Llama Stack configuration, and client code demonstrating RAG queries.
