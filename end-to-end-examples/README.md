# End-to-End Examples

**Status:** GA

Complete end-to-end workflows that combine multiple RHOAI capabilities into production-ready patterns. Each example demonstrates how platform components work together to solve real AI/ML use cases from data preparation through deployment.

## What's Covered

- Knowledge tuning: full pipeline from documents to deployed model
- MCP distillation: teaching small models to use tools
- RAG applications: retrieval-augmented generation with Llama Stack

## Official Documentation

- [Red Hat AI Examples](https://github.com/red-hat-data-services/red-hat-ai-examples)

## What's in examples/

Each subdirectory contains a self-contained end-to-end workflow with step-by-step instructions, required manifests, pipeline definitions, and scripts to reproduce the full pipeline on an RHOAI cluster.
